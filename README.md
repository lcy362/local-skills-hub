# Skills Hub

**让 skill 成为个人资产。**

Skills Hub 是一个本地优先的个人 AI Skills 资产管理器——集中管理你所有 Agent 使用的 skill，统一打标签、筛选、去重、投放到各 Agent 与项目目录。

## 核心理念

### 让 skill 成为个人资产

就像用obsidian来管理个人知识库：你的 skill 仓库是你自己的、**与任何单一系统都不强相关**的个人资产。它只存在于本地文件系统里，你可以用 git 或任何你喜欢的系统对它进行管理和版本控制；将来迁移到别的工具、别的生态，这份「资产」照常带走照常使用，不被本工具绑定。

### 你的 skill 是你的文件

skill 本体就是磁盘上的普通目录（`SKILL.md`），标签等元数据用开源生态认可的方式存放，而不是私有数据库。你随时可以直接打开、编辑、diff、提交这些文件——你始终握有全部数据。

### 尽量贴合开源生态

标签等元数据优先落在生态里已有共识的位置：

- **Skill 文件顶层** **`tags`（推荐）**：写在每个 `SKILL.md` 的 frontmatter 顶层，被 Claude Code、agentskills.io 等 40+ 工具原生读取，随 skill 目录和 git 一并版本化——这是最有可能统一开源生态的标签载体。

- **Claude Plugin 结构（可选）**：用 `.claude-plugin/marketplace.json` 的 `plugins[].keywords` 承载标签，与 Claude 生态兼容。

唯一刻意保留的分离，是**用户自己的管理信息不与外部 skill 库本体耦合**：当仓库来自外部（例如从 GitHub 拉下来的现成 skill 仓库），其中的 SKILL.md 是别人的内容、还会随上游更新。此时可把标签放到仓库内或仓库外的单独文件里，这样你本地对这批 skill 的归类，与外部本体互不干扰，也不污染上游文件。

### 尽量降低生态碎片化

同名 skill 多来源时自动去重保留一份；重复、分歧、失效引用都集中在一处看清并就地处理，避免同一份 skill 在环境中以多个副本反复膨胀。

## 第一次使用

整个流程分「必要」与「进阶」两层。**迈出第一步，只需要四条必要步骤：安装、添加仓库、添加 preset、把 preset 应用到 agent。** 其余都是让体验更完整的可选操作。

### ✅ 必要流程

#### 1. 安装

环境要求：Node.js ≥ 20。

```bash
npm install
npm run dev
```

- 前端（Web UI）：http://localhost:5173/
- 后端（API）：http://localhost:8787/

配置与状态存在 `~/.skills-hub/config.json`。

#### 2. 添加仓库

仓库是 skill 的集合/事实源，对应磁盘上一个目录。在「技能库」页底部的「来源与仓库」区点 **「登记库」**：

- **自有仓库**：填 id 与目录路径。点路径框右侧的「选择…」可直接调起系统目录选择器（也可手输/粘贴绝对路径）。
- **第三方技能库**：同样填路径，保持「只读关联」以便上游保持干净；需要接管时再点「收编」。

#### 3. 添加 preset

在侧栏「预设」页点「新建预设」，决定一批 skill 归为一类。一个 preset 就是一份 skill 套餐。

#### 4. 将 preset 应用到 agent

在「设置」把你的 Agent 加入**活跃集合**（也可在「智能体」详情页点「设为活跃」：加入即刻同步就位）。再把刚建的 preset 激活——所有活跃 Agent 会立刻拿到这套 skill，skill 便开始在对应 AI 编程生效。

> 至此，「建仓库 → 配 preset → 投给 agent」的最小通路已打通，你的 skill 已经可以工作。

### 🔸 进阶（可选）

- **导入 skill**：「技能库 → 导入」点「添加目录…」调起系统目录选择器逐个添加（也可手输，每行一个；支持扁平 / 嵌套分类 / 带索引清单三类结构）→「识别」→「开始导入」；同名 skill 自动去重。也可从已安装的 Agent「归集」。
- **整合向导**：「技能库 → 整合向导」扫描各 Agent 与仓库，同名多来源时让你确认保留哪个版本，未入库的可就地收编。
- **第三方库**：登记为「只读关联」保持上游干净，需要接管时点「收编」把本体拷进仓库。
- **浏览与筛选**：所有列表统一支持「卡片 / 列表」两种视图（默认卡片，偏好全局记忆）；「技能库」的搜索、来源、标签、未打标签条件集中在同一条筛选栏，条件生效时右侧出现「重置」一键清空。
- **打标签**：「技能库」点卡片打开详情，标签区增删；详情内可直接预览 SKILL.md 与来源追溯。
- **页面状态随地址保存**：一级页面、二级详情与筛选条件都写进地址栏，刷新或分享链接都能回到同一视图。
- **项目专属 skill**：用「项目」模块登记路径 + 标签，匹配的 skill 进入项目 `.agents/`；团队改动后可「回写仓库」。
- **体检与去重**：「诊断」页查看重复 skill、分歧、失效引用，支持一键修复。
- **同步策略**：默认软链；在「智能体」详情页可按 Agent 或按单个技能切换为复制。复制模式如需增量同步，到「设置」按需开启 watcher（默认关闭）。
