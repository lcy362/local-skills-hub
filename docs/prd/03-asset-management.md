# 流程三 PRD：资产管理 · 打标签 / preset / 分发

> 覆盖：流程三-A（浏览资产库与打标签）、流程三-B（维护 preset）、流程三-C（Agent 管理）。
> 依据：`docs/user-flows.md` 流程三。对应 data-flow §4.2（期望集 → 触发式分发）。
> 前提：资产已入库就位。此后用户只做"决策"，其余全靠触发。

---

## 1. 目标
- 浏览检索资产并**编码用户语义（打标签）**；
- 用标签/手工**组织 preset 套餐**；
- 通过 **Agent 管理**（模式、显式开关、活跃集合）把期望集**投影到物理目录**。

## 2. 用户场景
- 想快速找到某类技能，或补齐未打标签的资产。
- 想给"后端开发"建一套 preset，绑到对应 Agent。
- 想在某 Agent 上临时开/关某个 skill，或把某个 Agent 设为实时同步。

## 3. 用户操作流程

### 3.1 流程三-A · 浏览资产库与打标签
**浏览 / 过滤维度**
| 方式 | 说明 |
|---|---|
| 名称 / 全文搜索 | 按名称、描述模糊检索 |
| 按标签过滤 | 多标签且/或 |
| 按来源过滤 | 自有 vs 第三方（下钻来源命名空间） |
| 未打标签过滤 | 一键列出无标签资产，用于补全 |
| 状态视图 | 激活/未激活、分发到哪些 Agent、被哪些 preset 引用 |
| 查看详情 | 版本、描述、来源、标签（含仓库自带）、归属 |

**打标签**
| 场景 | 载体 | 触发效果 |
|---|---|---|
| 自有 skill | SKILL.md frontmatter tags | 重算项目关联与投放 |
| 第三方（两套体系） | 探测显示的体系（仓库自带读 / hub 管理写） | 同上 |
| 批量打标 | 按每项来源选载体 | 逐项触发变更 |

**标签元操作**：打/删/改单个标签、全局重命名标签、合并标签、补全清单、一致性检查（防多载体漂移）。

### 3.2 流程三-B · 维护 preset
| 步骤 | 用户操作 | 工具响应 |
|---|---|---|
| P1 | 新建 preset：命名→挑成员（逐个/按标签批量/复用）→绑定 Agent | 记 presets[]；成员=skillMeta 引用 |
| P2 | 激活 | 并入目标 Agent 期望集；对活跃 Agent 触发分发 |
| P3 | 增删成员 | 增量触发分发 |
| P4 | 调整绑定 | 旧 Agent 回退、新 Agent 投影 |
| P5 | 取消激活 | 移出期望集触发回退；成员与集合保留 |
| P6 | 复用组织 | 复制/跨 Agent 复用/按标签重组 |
| P7 | 手动兜底 | 单 Agent/全局全量对账 |

### 3.3 流程三-C · Agent 管理
| 步骤 | 用户操作 | 工具响应 |
|---|---|---|
| N1 | 扫描 Agent；覆盖 globalDir/同步方式/归属目录 | 内置清单+用户覆盖 |
| N2 | 选管理模式（preset / manual） | 决定期望集基准 |
| N3 | 对某 Agent 显式开/关某 skill | 记 explicitOn/Off；增量分发 |
| N4 | 加入 activeAgents | 加入即就位，立即对账 |
| N5 | 移出 activeAgents | 移出即回退，恢复懒同步 |
| N6 | 立即生效 | 单 Agent 全量对账 |
| N7 | 启/停/移除登记 | 停用保留配置；移除清登记与软链 |

## 4. 核心功能点
1. **多维浏览过滤**：名称/标签/来源/未打标签/状态/详情。
2. **标签载体自适应**：自有写 frontmatter，第三方写仓库内/外文件，按来源选载体。
3. **标签元操作**：重命名、合并、补全、一致性检查。
4. **preset 编排**：创建/激活/增删/换绑/取消/复用，成员按引用不复制。
5. **Agent 三要素管理**：覆盖配置、管理模式、显式开关；活跃集合即同步作用域。

## 5. 规则与边界
- **方案选择先判来源归属**：载体先判断自有 vs 外部，再选位置（C14）。
- **标签即策略**：标签改动立即重算期望集与关联（C6/C7），全程幂等。
- **同步只作用于活跃集合**：非活跃懒同步，不得静默扩散（C12/AA-03）。
- **explicit 存 name@source**：配置层统一标识，仅投影层归一化（G2 待定稿）。
- **期望集运行时计算，不落盘**（C6）。
- 第三方标签**不落库内本体**（C3）。

## 6. 异常与降级
- 跨来源批量打标签：按各 skill 来源自动选载体；无法统一载体时逐项提示确认。
- 「加入即就位」对账耗时：返回同步 diff 摘要作为就位反馈（对应 G6）。

## 7. 验收标准
- 任意标签 / preset / explicit / 活跃集合变更后，活跃 Agent 物理目录与期望一致。
- 非活跃 Agent 不被自动改动，进详情页「立即生效」才对账。
- 第三方 skill 打标签不写其库内本体；两套体系开关行为符合探测规则。
- preset 两次激活/取消，投影结果与首次一致（幂等）。
